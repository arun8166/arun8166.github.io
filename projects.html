Modular DSP Engine for Audio Processing

Personal project

A modular DSP engine in C++ with configurable signal-processing graphs built from reusable DSP blocks.

  • FIR/IIR filters, FFT-based spectral analysis, transfer functions and convolution modules for digital audio.
  • Multichannel audio buffers, parameter smoothing, module chaining and efficient memory management for real-time processing.
  • Extensible equalization, dynamic range, modulation, oscillator and envelope-based synthesis modules.

Safe Building OS Prototype

CS637: Embedded and Cyber-Physical Systems

Building-management middleware based on the paper Playground: A Safe Building Operating System. It mediates third-party control over core building infrastructure while keeping the building physically safe.

  • A safety pipeline of pre-write guards and live telemetry monitors that blocks unsafe commands.
  • A multi-tenant App Steward that manages app lifecycles and isolates untrusted apps with per-instance API keys and rate limits.
  • An extension for safe policy rollouts, so administrators can test new safety rules on live traffic before enforcing them.

Python

Custom MIPS-32 Processor

CS220: Intro. to Computer Organization &ndash

A 32-bit single-cycle processor in Verilog implementing a subset of the MIPS-32 instruction set, with floating-point and custom instructions.

  • Modular ALU, register file, control unit, instruction memory and data memory.
  • A Python instruction generator and Verilog testbenches that automate testing across modules.
